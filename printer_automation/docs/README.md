# Printer Automation

Projeto para automatizar consulta de contadores de impressoras via SNMP, geração de rascunhos de resposta por e-mail, validação e certificação de contadores.

Estrutura:
- `src/` : scripts Python
- `data/`: IPs, emails de entrada e saídas geradas (relatórios, rascunhos)
- `scripts/`: helpers (PowerShell) para criar venv e rodar
- `docs/`: documentação adicional
